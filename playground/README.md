# Playground (dev)

Локальная страница для отладки библиотеки без публикации в npm. Импортирует исходники напрямую из `../src/`, поэтому пересобирать корневой пакет не нужно — Parcel сам подхватит изменения.

```bash
cd playground
yarn install
yarn start           # http://localhost:1234
```

В отличие от `example/` (который ставит библиотеку через `link:..` и показывает реальное публичное использование), `playground/` рассчитан на быструю итерацию по коду в `src/`.

## Auto-upload demo (ImgBB)

Демо-секции «Auto-upload to ImgBB» требуют бесплатный API-ключ. Получить его на https://api.imgbb.com/, затем создать файл с ключом:

```
IMGBB_KEY=ваш_ключ_здесь
```

⚠️ **Важно про местоположение `.env`.** Поскольку `playground/yarn.lock` намеренно удалён (чтобы Parcel-watcher видел изменения в `../src/`), Parcel считает project root корнем репозитория и ищет `.env` именно там. Положи файл в корень репо (`react-easy-dropzone/.env`) либо сделай симлинк:

```bash
# из корня репо
ln -sf playground/.env .env
```

Оба файла загитигнорены. После создания/изменения `.env` Parcel нужно перезапустить — он читает env-переменные один раз при старте.

Загруженные изображения хранятся 24 часа (`expiration=86400`). Без ключа дропзоны всё равно работают, но загрузка падает с понятной ошибкой и кнопкой retry.
